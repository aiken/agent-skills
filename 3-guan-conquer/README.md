# 3关攻克模型交付物

初中数学单个知识点的完整学习材料生成系统。为北京中考（初二/初三）设计，包含：学习网站 + 第1天检测PDF + 7天后复活检测PDF。

## 交付物清单

| # | 文件 | 用途 | 给谁 |
|---|------|------|------|
| 1 | `01_core_card.html` | 核心概念卡片 | 孩子 |
| 2 | `02_level1_understand.html` | 理解关3题 | 孩子 |
| 3 | `03_level2_precise.html` | 精准关3天 | 孩子 |
| 4 | `04_level3_transfer.html` | 迁移关1题 | 孩子 |
| 5 | `index.html` | 导航首页 | 孩子 |
| 6 | `05_revival_test.html` | 提示页 | 占位 |
| 7 | `第1天检测_知识点.pdf` | 当天检测（学生+家长断开） | 家长打印 |
| 8 | `复活检测_知识点.pdf` | 7天后检测（学生+家长断开） | 家长打印 |

## 使用方式

1. 把 SKILL.md 和 agent.md 放入 Agent 的上下文
2. 用户给出一个知识点（如"胡不归模型"、"一元二次方程"）
3. Agent 按工作流程生成8个交付物
4. 部署网站 + 交付PDF

## 关键设计原则

- **不超纲**：初二下学期不出现三角函数、余弦定理等
- **图例准确**：所有几何图坐标用Python精确验证
- **文字不重叠**：短text标签加白色背景rect
- **分页断开**：PDF学生卷和家长判题页独立分页
- **错选DNA**：每道选择题都有4种错选模式的根因分析
- **家长友好**：判题标准清晰，不需要家长懂数学
