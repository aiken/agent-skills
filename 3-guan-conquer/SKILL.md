# 3关攻克模型 · 初中数学知识点交付物

## 概述

为北京中考数学（初二/初三）单个知识点的完整学习材料生成系统。交付物包括：
- **学习网站**（手机浏览器直接打开）：核心卡片 + 3关习题（理解关/精准关/迁移关）
- **第1天检测PDF**（家长打印）：学习当天检测基础概念
- **7天后复活检测PDF**（家长打印）：7天后检测是否真懂

## 交付物清单

| # | 文件 | 用途 | 给谁 |
|---|------|------|------|
| 1 | `01_core_card.html` | 核心概念卡片：3法则/3步证明/典型错误 | 孩子学习 |
| 2 | `02_level1_understand.html` | 理解关3题：概念识别/简单应用/易错辨析 | 孩子做题 |
| 3 | `03_level2_precise.html` | 精准关3天：周一至三，同构训练 | 孩子做题 |
| 4 | `04_level3_transfer.html` | 迁移关1题：仿海淀一模风格，含评分标准 | 孩子做题 |
| 5 | `index.html` | 导航首页 | 孩子进入 |

| 8 | `复活检测_知识点名.pdf` | 7天后检测：学生卷+家长判题页（断开分页） | 家长打印 |

## 工作流程

### Step 1: 分析输入

用户输入通常包含：
- **知识点名称**（如"将军饮马双对称模型"、"根式运算"）
- **学生信息**（年级、已学内容、常见错题模式）
- **中考位置**（北京中考第几题）

### Step 2: 检查超纲内容

**强制检查：初二下学期不能出现的内容**
- ❌ 三角函数（sin/cos/tan）→ 用勾股定理替代
- ❌ 余弦定理 → 用等腰三角形三线合一 + 勾股定理
- ❌ 斜率/直线方程 → 用坐标系 + 轴对称
- ❌ 相似三角形 → 如果有，确认初二已学

### Step 3: 设计核心卡片

核心卡片必须包含6个模块：

```
📌 触发条件（关键词 → 启动检查清单）
📌 核心三法则/三步证明
📌 正确做法示范（完整例题 + 分步解答）
📌 3个典型错误（每个带根因分析）
📌 必须记住的数值表（如根式值常识表、勾股数表）
📌 前置/后续影响（知识点在知识体系中的位置）
```

### Step 4: 设计3关习题

**理解关（3题，限时3分钟）**
| 题号 | 类型 | 功能 |
|------|------|------|
| 1 | 概念识别 | 识别模型/公式的适用场景 |
| 2 | 简单应用 | 直接套用核心法则 |
| 3 | 易错辨析 | 判断"小明的错在哪" |

每题带：选项 → 正确答案 → 分步解答 → **错选DNA分析**（家长判题用）

**精准关（周一至三，每天1题，限时5分钟）**
- 周一：基础题型（掌握核心操作）
- 周二：含陷阱变式（绝对值/符号/隐藏条件）
- 周三：综合混合运算（多个公式联动）

每题带：题目 → 解题思路 → 分步解答 → **家长判题标记点**（打勾清单）

**迁移关（1题，仿海淀一模风格，限时10分钟，满分10分）**
- 换载体：等边三角形/正方形/坐标系
- 多问连环：(1)基础 → (2)进阶 → (3)陷阱
- 含评分标准明细（每问几分，踩分点在哪里）

### Step 5: 设计第1天检测PDF

**学生卷（2页）**
- 封面：知识点名、限时5分钟、满分10分
- 3道变式题（不是理解关原题，换数字/换载体）
- 每题配图（几何题必须有SVG图，坐标精确）
- 答题区（画线格子）

**家长判题页（独立分页，1-2页）**
- 每题答案 + 判题标准
- 错因分析
- 结果分级（8-10分/5-7分/0-4分）
- 后续行动建议

### Step 6: 设计7天后复活检测PDF

与第1天检测结构相同，但：
- 题目难度提升（换载体/换组合方式）
- 限时8分钟
- 家长话术：不提示"这是XX模型"，让孩子自己识别

### Step 7: 生成与部署

1. 生成所有HTML文件（模板见 `templates/` 目录）
2. 生成PDF（使用HTML+Paged.js路线）
3. 部署网站
4. 交付所有文件

## 技术规范

### HTML规范
- 移动端优先：width 320-360px，font-size 12-16px
- 不用外部CSS库，全部内联
- SVG几何图：所有坐标用Python精确计算，验证角度和距离
- 文字标签：短text（P/P₁/P₂/A/B等）加白色背景rect防重叠

### PDF规范
- A4尺寸
- 封面：210mm × 297mm，full-bleed，无外边距
- 学生卷和家长判题页**必须断开分页**（用独立分页元素）
- 不用Google Fonts，使用系统字体（SimSun/STSong/SimHei）
- 几何题PDF必须有SVG图，坐标精确验证

### SVG坐标验证清单
每生成几何图后，用Python验证：
```python
# 1. 角度验证：计算两线夹角，应为题目指定值
# 2. 距离验证：OP₁应等于OP（轴对称保距）
# 3. 点在直线上验证：A点在OM上，参数t应在[0,1]
# 4. 对称点验证：P₁应是P关于直线的精确对称
```

## 质量标准

- **不超纲**：所有内容必须匹配学生年级已学知识
- **图例准确**：每道几何题SVG坐标精确，角度/距离/对称关系正确
- **文字不重叠**：text标签有白色背景rect，不与circle/line重叠
- **分页断开**：学生卷和家长判题页在PDF中独立分页
- **错选DNA**：每道选择题都有4种错选模式的根因分析
- **家长友好**：判题标准清晰，不需要家长懂数学也能判分
