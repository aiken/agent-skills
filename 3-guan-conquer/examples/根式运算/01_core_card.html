📌 核心三法则
法则一：双重非负性
√a 有意义 ⇔ a ≥ 0，且 √a ≥ 0

根号下的数必须非负，根号的结果也必须非负。负数不能开平方！

法则二：化简公式
√(a²) = |a|    √(ab) = √a · √b (a≥0, b≥0)    √(a/b) = √a / √b (a≥0, b>0)

最危险的是 √(a²) = |a|，不是等于 a！必须判断 a 的正负才能去掉绝对值。

法则三：绝对值处理
|a| = a (a≥0)    |a| = -a (a<0)

判断根式大小：√2≈1.414，√3≈1.732，√5≈2.236。必须记住这三个近似值！

✅ 正确做法示范
例题：化简 |1-√3| + √(√3-2)²

第一步：判断正负
∵ √3 ≈ 1.732 > 1，∴ 1-√3 < 0
∵ √3 ≈ 1.732 < 2，∴ √3-2 < 0

第二步：去绝对值和根号
|1-√3| = -(1-√3) = √3-1
√(√3-2)² = |√3-2| = -(√3-2) = 2-√3

第三步：合并
原式 = (√3-1) + (2-√3) = 1

⚠ 3个典型错误

  1. 根式值常识缺失：不知道√3≈1.732>1，导致|1-√3|错算成1-√3。
    ✓ 必须背熟：√2≈1.414，√3≈1.732，√5≈2.236
  2. √(a²) = a：忘记先加绝对值，直接等于a。正确：√(a²) = |a|。
  3. 合并时漏系数：3√2 - √2 = 2√2（不是2或2√4）。
    ✓ 同类二次根式才能合并，系数相加减，根号部分不变
