周一
题目：基础化简与合并
计算：√12 - √(1/3) + √(27/4)

📝 解题思路（孩子照着手绘复现）

1
把每个根式化为最简二次根式。
2
检查被开方数是否相同（同类二次根式才能合并）。
3
系数相加减，根号部分不变。

✅ 分步解答

第一步：分别化简
√12 = √(4×3) = √4 × √3 = 2√3
√(1/3) = √1 / √3 = 1/√3 = √3/3（分母有理化）
√(27/4) = √27 / √4 = (3√3) / 2 = 3√3/2
第二步：合并同类项
原式 = 2√3 - √3/3 + 3√3/2
通分（公分母为6）：
= (12√3)/6 - (2√3)/6 + (9√3)/6
= (12-2+9)√3 / 6 = 19√3/6

📋 家长判题标记点

标记点①：√(1/3) 是否做了分母有理化（写成 √3/3，不是 1/√3）。
标记点②：合并时是否统一了分母（公分母找6，不是随意通分）。
标记点③：最终结果是否为 19√3/6（不能写成小数近似值）。
周二
题目：含绝对值的根式化简
计算：|√2 - √3| + √(√3-2)² - |1-√2|

📝 解题思路

1
判断每个绝对值内部和根号内部的正负。
2
利用 √(a²) = |a| 化简根号部分。
3
去绝对值，注意符号变化。
4
合并同类二次根式。

✅ 分步解答

第一步：判断正负（核心！）
√2 ≈ 1.414, √3 ≈ 1.732
√2 - √3 ≈ 1.414 - 1.732 = 负数 → |√2-√3| = -(√2-√3) = √3-√2
√3 - 2 ≈ 1.732 - 2 = 负数 → √(√3-2)² = |√3-2| = 2-√3
1 - √2 ≈ 1 - 1.414 = 负数 → |1-√2| = -(1-√2) = √2-1
第二步：代入原式
原式 = (√3-√2) + (2-√3) - (√2-1)
第三步：去括号合并
= √3 - √2 + 2 - √3 - √2 + 1
= (√3-√3) + (-√2-√2) + (2+1)
= 3 - 2√2

📋 家长判题标记点

标记点①：三个正负判断全对（尤其是√2-√3为负）。
标记点②：去绝对值时符号处理正确（负数变号）。
标记点③：最终结果是否为 3-2√2（不是3-√8或其他形式）。
周三
题目：综合混合运算
计算：(√5 + √3)(√5 - √3) - (√2 + 1)² + √(1/2) × √8

📝 解题思路

1
第一部分用平方差公式：(a+b)(a-b) = a²-b²。
2
第二部分用完全平方公式：(a+b)² = a²+2ab+b²。
3
第三部分用乘法公式：√a × √b = √(ab)。
4
合并所有结果。

✅ 分步解答

第一部分：平方差
(√5 + √3)(√5 - √3) = (√5)² - (√3)² = 5 - 3 = 2
第二部分：完全平方
(√2 + 1)² = (√2)² + 2×√2×1 + 1² = 2 + 2√2 + 1 = 3 + 2√2
第三部分：根式乘法
√(1/2) × √8 = √(1/2 × 8) = √4 = 2
（或者：√(1/2) = √2/2，√8 = 2√2，相乘 = (√2/2)×(2√2) = 2）
第四步：合并
原式 = 2 - (3 + 2√2) + 2
= 2 - 3 - 2√2 + 2
= 1 - 2√2

📋 家长判题标记点

标记点①：平方差公式应用正确（得到2，不是5-3的其他形式）。
标记点②：完全平方中间项 2ab 没漏（是2√2，不是√2）。
标记点③：第三部分 √(1/2)×√8 化简正确（是2，不是4或1）。
标记点④：最终结果是否为 1-2√2。
