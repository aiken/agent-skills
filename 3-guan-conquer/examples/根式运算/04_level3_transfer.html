综合计算题

已知 a = √3 + 1，b = √3 - 1。求下列各式的值：

(1) a² + b²；    (2) a/b + b/a；    (3) √(a² - 2ab + b²)

✅ 完整解答与评分标准

第(1)问：求 a² + b²（3分）
方法一：直接展开
a² = (√3+1)² = 3 + 2√3 + 1 = 4 + 2√3
b² = (√3-1)² = 3 - 2√3 + 1 = 4 - 2√3
a² + b² = (4+2√3) + (4-2√3) = 8
（评分：展开各1分，合并1分）

方法二：用公式 a²+b² = (a+b)² - 2ab
a+b = (√3+1)+(√3-1) = 2√3
ab = (√3+1)(√3-1) = 3-1 = 2
a²+b² = (2√3)² - 2×2 = 12-4 = 8
第(2)问：求 a/b + b/a（4分）
步骤1：通分
a/b + b/a = (a²+b²)/ab

步骤2：代入
由(1)知 a²+b² = 8，由上面知 ab = 2
∴ 原式 = 8/2 = 4
（评分：通分1分 + 代入a²+b²和ab各1分 + 结果1分）

易错警示：直接代入a=√3+1, b=√3-1到a/b中，分母有理化极容易出错。
用整体代换 (a²+b²)/ab 是最优策略。
第(3)问：求 √(a²-2ab+b²)（3分）
步骤1：识别公式
a²-2ab+b² = (a-b)²
∴ √(a²-2ab+b²) = √((a-b)²) = |a-b|

步骤2：计算 a-b
a-b = (√3+1)-(√3-1) = √3+1-√3+1 = 2

步骤3：去绝对值
|a-b| = |2| = 2
（评分：配方1分 + 计算a-b 1分 + 结果1分）

易错警示：√((a-b)²) 不能直接等于 a-b，必须先写 |a-b|。
虽然这里a-b=2是正数，但步骤分要求写绝对值！

📊 评分标准明细（满分10分）

第(1)问：展开/公式应用1分 + 代入1分 + 结果1分 3分
第(2)问：通分1分 + 整体代换2分 + 结果1分 4分
第(3)问：配方/绝对值1分 + 计算a-b 1分 + 结果1分 3分
🔍 关键发现：本题三问层层递进，(2)和(3)都可以用(1)的结果。如果(1)算错，后面全错——这就是中考"连环计"出题套路。
