题目：计算下列各式：

(1)  |√3 - 2| + √(2√3 - 3)²

(2)  (√5 + √3)(√5 - √3) - (√2 - 1)²

要求：写出详细的化简步骤，结果保留根式形式。

提示：√3 ≈ 1.732，√2 ≈ 1.414。先判断正负，再去绝对值。

解答区（第2题）

家长判题页（请勿提前给孩子看）

第(1)题答案：√3 - 1 第(2)题答案：2√2 - 1

判题标准（暗中观察，不打断孩子）

  1. 根式值常识（3分）：是否正确判断了 √3≈1.732 与 2 的大小关系（1-√3 为负、2√3-3 为正）。
    正负判断错误 → 后续绝对值全错，扣 3 分。
  2. 公式应用（3分）：是否正确使用 √(a²) = |a|，而不是直接等于 a。
    漏写绝对值步骤 → 扣 1 分；公式完全记错 → 扣 3 分。
  3. 计算终点（4分）：最终结果是否化简到最简形式。
    结果写成小数近似值 → 扣 2 分；合并同类项出错 → 扣 2 分。

完整推导过程（供家长参考）

第(1)题：

  1. 判断正负：√3 ≈ 1.732，∴ √3 - 2 < 0，2√3 - 3 ≈ 3.464 - 3 > 0。
  2. |√3 - 2| = -(√3 - 2) = 2 - √3。
  3. √(2√3 - 3)² = |2√3 - 3| = 2√3 - 3（∵ 2√3 - 3 > 0）。
  4. 原式 = (2 - √3) + (2√3 - 3) = √3 - 1。
  1. (√5 + √3)(√5 - √3) = (√5)² - (√3)² = 5 - 3 = 2（平方差公式）。
  2. (√2 - 1)² = (√2)² - 2×√2×1 + 1² = 2 - 2√2 + 1 = 3 - 2√2（完全平方）。
  3. 原式 = 2 - (3 - 2√2) = 2 - 3 + 2√2 = 2√2 - 1。

结果分级与后续行动

8-10 分 对且步骤全 → 该知识点正式通关，可进入下一知识点。
4-7 分 对但步骤不全 → 记忆型做对，建议回退精准关。
0-3 分 错或完全没思路 → 回退到理解关重新开始。
